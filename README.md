# Teacher IPC · Dallas ISD Math

A planning page for Dallas ISD math teachers: the 2026-27 IPC week by week for ten courses (Accelerated Grade 6 through Algebra II Advanced), each lesson's TEKS, teaching moves, released STAAR items, and AI-generated practice items for Geometry and Algebra II.

Open `index.html` (GitHub Pages). It opens on **This week**. See `NOTES.md` for how the data is organized and how practice items are reviewed.

Teaching moves are suggestions, not a complete list, and not a checklist for evaluating teacher instruction or performance.
